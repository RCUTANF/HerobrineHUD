# HerobrineHUD - Minecraft 电竞导播系统

HerobrineHUD 是一款专为 **Minecraft 电子竞技（E-sports）**、赛事直播与专业导播环境设计的 MOD。目标是能够面向无论是大型赛事，还是多人小游戏，都能提供良好的导播体验。
我们的理念是：Minecraft从来不缺好玩的游戏，但缺乏让好玩的游戏变得好看的系统级界面展示工具。

## ✨ 核心功能 (Features)

目前本模组已做到**开箱即用（无配置文件负担）**。只需要在服务器和希望显示 HUD 的客户端同时安装此 Mod，客户端即可无缝显示队伍信息和选手状态。原版的 `/team` 组队指令会自动同步成导播面板的队伍分组。

导播/操作热键说明：
- **按键 `H`**：快速切换 HUD 的显示与隐藏。
- **按键 `K`**：打开 HUD 队伍管理、设置与选项菜单界面，允许你自定义启用或关闭特定元素（如装备栏、药水状态等），同时管理左右两边要展示的玩家。
- **小键盘按键（Numpad 1~9, 0）**：**快速导播切镜**。当你处于旁观者模式 (Spectator) 时，只需按下小键盘对应的快捷键区块数字（对应屏幕上排序的选手编号），镜头便会瞬时平滑锁定至对应的比赛选手视角！

## 🚀 未来计划
这个 mod 使用标准的 GSI 协议理念设计，我也计划预留以下接口来方便其他 mod 进行拓展乃至构建出大型生态系统：

* GSI 协议中将预留更多游戏状态字段（未来改造成对外开放的 API 接口），允许其他第三方 Mod 随时将特殊玩法或规则数据也接入 HUD 渲染中。
* 服务端将预留将数据化作 HTTP 实时服务广播的接口。以后可支持纯外部程序接收数据，随后通过 Web 技术构建出专属的第三方直播界面（例如快速化作 OBS 的浏览器源，无需在游戏内录屏）。

## 🗺️ 路线图 (Roadmap)
* 迁移现有的专有 Mixin 至高兼容的 Architectury API 以打好跨平台地基
* 迁移工程代码架构以拥抱针对多版本 (Multiversion) 的自动构建
* 引入 AUI 框架，在游戏内原生地使用 Web 技术来更灵活地渲染那些炫酷且定制化极强的 Web 风格 UI
* 提供丰富的 UI 主题框架与 Theme Manager 支持
